IMMEDIATE ACTION REQUIRED: NODE.JS INSTALLATION
==========================================
The application cannot run because Node.js is missing from your system.

1. Download Node.js
   - Visit: https://nodejs.org/
   - Download the "LTS" (Long Term Support) version.

2. Install
   - Run the installer.
   - Accept default settings (ensure "Add to PATH" is checked).

3. Activate
   - CLOSE your current terminal or VS Code window completely.
   - Open a NEW terminal.
   - Verify installation by running: node -v

RUNNING THE APP
===============
Once Node.js is installed:
1. Open terminal in project root.
2. Run: npm install
3. Run: npm run dev
4. Open http://localhost:5173 (or port shown in terminal).
