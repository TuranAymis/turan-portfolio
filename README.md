## English

### About the project

This repository contains the source code of my personal portfolio website.

The website presents my professional background, Software QA experience, technical skills, projects, certifications, achievements, and contact information through an interactive and responsive interface.

**Live website:** [www.turanaymis.com](https://www.turanaymis.com)

### Features

- Professional profile and career summary
- Software QA skills and technology overview
- Work experience and project sections
- Certifications and achievements
- Turkish and English content
- Responsive design
- SEO metadata and structured data
- Contact and social media links

### Technology stack

- React 19
- TypeScript
- Vite 6
- React Router
- React Helmet Async
- Lucide React
- CSS

### Local installation

#### Requirements

- Node.js
- npm

#### Setup

Clone the repository:

```bash
git clone https://github.com/TuranAymis/turan-portfolio.git
```

Enter the project directory:

```bash
cd turan-portfolio
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local address displayed in the terminal. The default Vite development address is usually:

```text
http://localhost:5173
```

### Production build

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
